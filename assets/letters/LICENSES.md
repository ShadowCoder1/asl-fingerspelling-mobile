Source: Wikimedia Commons, the "Sign language A.svg" ... "Sign language Z.svg" set (wpclipart.com hand-drawn ASL fingerspelling clip art). Retrieved 2026-09-20 via the Commons API
(`https://commons.wikimedia.org/w/api.php?action=query&titles=File:Sign_language_<L>.svg&prop=imageinfo&iiprop=url|extmetadata&format=json`), one request at a time, with a descriptive User-Agent
(`physical-tutor-research/0.1 (local research prototype)`).

Every one of the 26 files carries `extmetadata.LicenseShortName = "Public domain"` (per-image `{{PD-author}}` template, credited to wpclipart.com, which released its clip art into the public domain -- see each file page for the exact wording). No file was guessed at: this table is built from what the API actually reported, not from an assumption that the whole set is public domain because a few files are.

**What these drawings show.** Each SVG is the VIEWER's view of the handshape -- what another person, watching the signer's hand, sees -- not the signer's own view of their hand. The tutor shows the caption "What the other person sees." (letters.js `PICTURE_CAPTION`) under every picture. These are generic clip art, NOT validated by a Deaf signer, and are a placeholder until Deaf-signer-validated reference images exist -- they should not be presented as a vetted teaching resource beyond that.

## Fix round 1 (2026-09-20): K, L, M, O retried and now shipped

The original fetch pass shipped 22/26 letters; K, L, M and O were confirmed public domain by the Commons API at the time (same "Public domain" license, same wpclipart.com author, as every other letter in this set -- the license check was never in question for any of them) but the SVG *download* from `upload.wikimedia.org` was rate-limited (HTTP 429, "Too many requests -- please contact noc@wikimedia.org ... or instead use thumbnail images") across two fetch passes with exponential backoff (up to four retries per file: 15s/30s/45s/60s).

A later retry the same day, spaced out (one request at a time, 6s pause, with Commons' `Special:FilePath` form -- `https://commons.wikimedia.org/wiki/Special:FilePath/Sign_language_<L>.svg`, which serves the same original file -- held in reserve as a fallback), got all four through on the first attempt via their original direct URLs; the `Special:FilePath` fallback was not needed. Each file passed the same sanity checks as the rest of the set (below), plus two additional checks requested in review: no event-handler attribute (`on*=`) and no external `href`. All 26 letters now have a shipped picture, so `PICTURE_LETTERS` in `tutor/letters.js` is the full alphabet.

## Sanity checks performed on every shipped file

For each of the 26 shipped SVGs: starts with `<?xml` (confirmed), non-trivial size (11-17KB, consistent with the hand-drawn line art in this set), contains no `<script` element, no event-handler attribute (`on*=`), and no external `href` (all confirmed, 0 matches on every file). Files were saved byte-for-byte as downloaded -- not stripped, minified, or otherwise altered.
