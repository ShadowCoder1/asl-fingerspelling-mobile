# Fonts

`nunito-latin.woff2` — **Nunito** (variable weight 400–800, Latin subset), by
Vernon Adams, Cyreal and Jacques Le Bailly. Licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/). Source:
<https://fonts.google.com/specimen/Nunito>.

It is served from this folder rather than from Google Fonts so that a
participant's browser makes no request to a third party for the sake of a
typeface. If the file is missing the page falls back to the system's rounded or
default UI font and everything still works.
